プライバシーポリシー

最終更新日: 2026年10月14日

QualiHal（以下「当社」）が提供するアプリ「GROW」（以下「本アプリ」）における、利用者情報の取り扱いについて、以下の通りプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 本アプリが取り扱う情報

本アプリはアカウント登録やログインを必要としません。氏名・メールアドレス・住所などの個人を特定する情報を収集することはありません。

1-1. 端末内にのみ保存される情報

以下の情報は、お使いの端末内にのみ保存され、当社のサーバーに送信されることはありません。アプリをアンインストールすると、これらの情報は端末から削除されます。

  • トレーニング記録（種目・重量・回数・セット数）
  • 食事記録（推定カロリー・タンパク質量・食事写真のサムネイル）
  • 体重・体脂肪率などの身体データ
  • 日々のコンディション（疲労度等）の記録
  • アプリの各種設定

1-2. 機能提供のために外部へ送信する情報

以下の情報は、該当する機能をご利用になった際にのみ、処理のため一時的に外部へ送信されます。当社のサーバー上に保存されることはなく、処理後は破棄されます。

情報送信先目的
食事の写真Google Gemini API写真からのカロリー・栄養素の推定
トレーニング実績の要約テキストGoogle Gemini API励ましメッセージの生成
音声コーチ用のテキストAzure Cognitive Services / Google Cloud Text-to-Speech / ElevenLabs音声読み上げ・BGM生成

これらの外部サービスへの送信は、当社が運営するサーバー（Firebase Cloud Functions）を経由して行われ、各外部サービスの提供者によって個別に保存されることはありません（各社のAPI利用規約に基づきます）。

1-3. 定期購入（サブスクリプション）に関する情報

本アプリの有料プランは、Google Playの定期購入機能を通じて提供されます。購入状態を確認するため、購入情報を識別するトークンを当社サーバーに送信し、有効性の確認のためGoogle Play Developer APIに照会します。このトークンは購入状態の確認のためにのみ用いられ、氏名・メールアドレス等のGoogleアカウント情報そのものを当社が取得することはありません。

確認結果はサーバー上に一時的にキャッシュされますが、このキャッシュには自動削除の設定（Cloud Firestore TTL）がなされており、最長でも24時間以内に自動的に削除されます。

2. 情報の利用目的

取得した情報は、以下の目的にのみ利用します。

  • 本アプリの基本機能（トレーニング・食事・身体記録の管理）の提供
  • 写真からの食事内容・カロリー推定（AIによる解析）
  • 音声コーチ・励ましメッセージ機能の提供
  • 定期購入の有効性確認

3. 第三者への提供

前項の目的の範囲内で、処理を委託する以下の外部サービス提供者に対してのみ情報を送信します。当社が第三者に情報を販売したり、広告目的で提供したりすることはありません。

  • Google（Gemini API, Play Developer API, Firebase）
  • Microsoft（Azure Cognitive Services）
  • ElevenLabs, Inc.

4. アクセス権限

本アプリは以下の端末機能へのアクセス許可を求めます。

  • カメラ: 食事の写真を撮影するため
  • インターネット通信: 上記のAI機能・購入確認のための通信を行うため

5. データの削除（GROW / 運営者: QualiHal）

本アプリ「GROW」（運営者: QualiHal）はアカウント登録を伴わないため、以下の方法でご自身のデータを削除できます。

データの種類削除方法保持期間
トレーニング記録・食事記録・体重/体脂肪率・コンディション記録（すべて端末内保存） 本アプリをアンインストールしてください。端末から即座に削除されます。 アンインストールするまで端末内に保存
定期購入の有効性確認用キャッシュ（購入トークン、サーバー保存） 自動的に削除されます。手動削除をご希望の場合は下記お問い合わせ先までご連絡ください。 最長24時間（Cloud Firestore TTLポリシーにより自動削除）

その他ご不明点やデータ削除に関するお問い合わせは、下記「8. お問い合わせ」までご連絡ください。

6. お子様のプライバシー

本アプリは13歳未満のお子様を対象としていません。

7. 本ポリシーの変更

本ポリシーの内容は、必要に応じて予告なく変更されることがあります。重要な変更がある場合は、本アプリ内または本ページにてお知らせします。
